# Combat Cataclysm 3D — Enemy Bible

## Enemy purpose
Enemies should create tactical questions and comedy opportunities. A good enemy changes how the player deploys units, not just how much HP must be removed.

## Enemy categories
- Swarm
- Tank
- Ranged
- Ambush
- Support
- Disruptor
- Summoner
- Money thief
- Anti-support hunter
- Boss
- Comedy wildcard

## Design template
Each enemy should define:
- ID and readable name
- Role
- HP / ATK / range / speed
- Trait tags
- Target priorities
- Counter relationships
- Status resistances
- Signature behavior
- Telegraph
- Death/reaction behavior
- Comedy hooks
- Boss/event hooks

## Boss rules
Bosses need identity beyond inflated stats. Each boss should have:
- Recognizable silhouette
- Intro beat
- 2–4 meaningful mechanics
- Clear telegraphs
- Phase or escalation logic where useful
- Unique camera/audio moment
- At least one interaction with the comedy systems

## Fairness
Unfair-looking attacks can be funny, but the player should understand what happened. Dangerous behaviors require telegraphing, counterplay or low frequency.

## Current prototype note
The existing prototype roster can remain during engine development. Canonical enemies may replace or reinterpret prototypes gradually rather than forcing a destructive rewrite.
