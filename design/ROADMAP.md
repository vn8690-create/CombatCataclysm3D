# Combat Cataclysm 3D — Studio Roadmap

## Phase 0 — Canonicalize the prototype
- Import the validated local prototype into GitHub
- Confirm `npm` install/run path
- Run smoke tests
- Tag the preserved playable baseline

## Phase 1 — Combat Feel
- hit stop
- knockback tuning
- impact anticipation/recovery
- squash/stretch hooks
- projectile readability
- damage and death feedback
- lightweight camera shake

Exit condition: combat feels punchy before additional content is added.

## Phase 2 — Comedy Director
- event priority queue
- one-major-beat-at-a-time rule
- freeze frame
- spotlight
- temporary UI suppression
- short slow motion
- reaction windows

Exit condition: hidden/combo events land clearly without visual spam.

## Phase 3 — Camera Director
- target framing
- zoom bands
- boss intro framing
- event focus
- shake budgets

## Phase 4 — Animation & Asset Pipeline
- canonical Character DNA schema
- turnaround/reference sheets
- expression sheets
- combat pose sheets
- animation state definitions
- asset naming conventions

## Phase 5 — Tactical Depth
- trait layer
- counter rules
- target priorities
- accuracy/evasion
- relationship events

## Phase 6 — Content Expansion
- official roster mapping
- bosses/elites
- encyclopedia with hidden entries
- World Tour country packs

## Phase 7 — Production Readiness
- performance profiling
- object pooling where needed
- save compatibility checks
- CI smoke tests
- release build and deployment

## Current sprint order
Combat Feel -> Comedy Director -> Camera -> Spotlight -> Animation.

Do not invert this order merely to add more characters.
