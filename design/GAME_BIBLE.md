# Combat Cataclysm 3D — Game Bible

## High concept
Combat Cataclysm is a comedy-first 3D side-view lane-defense game inspired by the readability and deploy-vs-base rhythm of games like Nyanko Daisenso, but built around absurd human characters, ridiculous enemies, emergent accidents, hidden interactions, and battlefield stories that can go gloriously wrong.

The player deploys a roster from the left side, manages money and timing, reacts to enemy composition, destroys the enemy base, and unlocks new characters, stages, upgrades and regions. The battlefield should be strategically readable, but never perfectly controllable: units have personalities, flaws, relationships and rare behaviors that can create unexpected comedy.

## Non-negotiable identity
1. Funny > Realistic
2. Funny > Balance
3. Funny > Logic
4. Readable chaos beats visual clutter
5. Hidden interactions should create stories players want to retell
6. Strategy exists to set up comedy, not suffocate it
7. The player commands an army, but the army is not always obedient
8. Every character should be recognizable by silhouette, behavior and personality

## Core battle loop
Choose stage -> select roster -> deploy units -> manage economy -> respond to enemy composition -> trigger interactions/comedy events -> destroy enemy base or survive encounter -> earn rewards -> upgrade roster -> unlock next stage/region.

## Combat identity
- Side-view single-lane battle with opposing bases
- Small readable battlefield units and strong silhouettes
- Distinct tactical roles, counters and support behavior
- Traits, targeting priorities, accuracy/evasion, status effects and specialist counters
- Rare hidden skills, relationship events and combo events
- Character behavior can occasionally override perfect tactical logic when comedy value is high

## Controlled chaos / friendly-fire philosophy
Friendly fire and accidental ally interference are a signature feature, not a universal random punishment.

Examples:
- A panicked unit throws an attack in the wrong direction
- A giant swing launches an ally instead of the enemy
- A doctor injects the wrong teammate
- A drunk character mistakes friend for foe
- A manager orders a ridiculous action that disrupts allies
- Knockback, explosions or props create chain reactions

Rules:
- Comedy events must be readable and visually telegraphed
- They should be uncommon enough to remain funny
- They must not make every match feel arbitrary
- Stronger negative effects should either be rare, recoverable, or offer an upside
- Important events should become memorable battlefield stories rather than invisible RNG

## Tactical roles
- Cheap ranged
- Tank
- Bruiser
- Support
- Ambush/counter
- Crowd control
- Specialist hard counter
- Chaos/comedy wildcard

## Character philosophy
A unit is not just HP + ATK. Each important character may contain:
- Combat role
- Personality
- Signature silhouette
- Normal skill
- Passive
- Hidden skill
- Rare failure behavior
- Relationship hooks
- Counter relationships
- Comedy event hooks
- Voice/reaction lines
- Animation personality

Characters should sometimes interact with each other rather than behave like isolated chess pieces.

Relationship examples:
- Friend
- Rival
- Fear
- Hate
- Crush
- Idol
- Annoyance

## Comedy delivery
Animation tells the joke. Text delivers the punchline.

Floating text should be rare. Large text is reserved for important moments such as boss intros, hidden skills, combo events and major comedy events. Reactions, timing, poses, camera work and physical consequences should carry most jokes.

## Two-layer long-term game structure

### Layer 1 — Main Battle Campaign
The primary mode is fast lane-defense combat: deploy, counter, survive, destroy the enemy base, unlock more content.

### Layer 2 — Boken / World Adventure
Later development expands into an adventure/exploration layer where the player travels across regions and countries around the world.

The adventure layer can include:
- World map travel
- Region nodes and hidden locations
- Short exploration scenes
- Local NPC encounters
- Comedy side quests
- Recruitable characters
- Local bosses
- Country-specific enemies and mechanics
- Collectibles and lore
- Surprise battle nodes
- Rare hidden characters/events

Battles remain the mechanical backbone. Exploration gives context, discovery, pacing and a reason to meet increasingly absurd characters around the planet.

## World Comedy Tour
Long-term fantasy: tấu hài xuyên quả đất.

Each country/region is a themed expansion with its own:
- Visual identity
- Local stage backgrounds
- Comedy flavor
- Unit roster
- Enemy roster
- Elite enemies
- Bosses
- Hidden boss/event
- Local props and hazards
- Exploration encounters

Recognizable cultural details should be celebrated rather than used to demean nationalities or ethnic groups. Humor should primarily target situations, jobs, habits, archetypes, game logic and absurd escalation.

Possible structure per mature country pack:
- 15–20 regular characters/enemies
- 3–5 elite units
- 2 major bosses
- 1 hidden encounter or secret boss
- Region-specific comedy mechanics

## Progression direction
Prototype -> polished vertical slice -> main campaign -> multi-region World Tour -> Boken exploration layer -> expandable country/character packs.

## Current production priority
Do not expand content too early. Current order:

Combat Feel -> Comedy Director -> Camera -> Spotlight -> Animation -> Character Factory -> relationship/chaos systems -> World Tour content -> Boken exploration.
