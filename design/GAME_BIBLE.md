# Combat Cataclysm 3D — Game Bible

## High concept
Combat Cataclysm is a comedy-first 3D side-view lane-defense game where ordinary-looking characters, bizarre specialists, and absurd enemies create memorable battlefield stories.

## Design pillars
1. Funny > Realistic
2. Funny > Balance
3. Funny > Logic
4. Readable chaos beats visual clutter
5. Hidden interactions should create stories players want to retell
6. Strategy exists to set up comedy, not suffocate it

## Core loop
Choose stage -> deploy units -> manage economy -> respond to enemy composition -> trigger character interactions and comedy events -> destroy enemy base or survive encounter -> earn rewards -> upgrade roster -> continue World Tour.

## Combat identity
- Side-view lane battle
- Strong silhouettes
- Small readable battlefield units
- Distinct tactical roles
- Traits, counters, targeting priorities, accuracy/evasion and support behavior
- Rare hidden skills and combo events

## Tactical roles
- Cheap ranged
- Tank
- Bruiser
- Support
- Ambush/counter
- Crowd control
- Specialist hard counter

## Comedy delivery
Animation tells the joke. Text delivers the punchline.

Floating text should be rare. Large text is reserved for important moments such as boss intros, hidden skills, combo events and major comedy events.

## Progression direction
Prototype -> polished vertical slice -> multi-country World Tour -> expandable character/country packs.

## World Tour principle
Countries are playful expansions inspired by recognizable culture. Celebrate recognizable details without demeaning cultures or nationalities.
