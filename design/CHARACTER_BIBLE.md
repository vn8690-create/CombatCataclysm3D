# Combat Cataclysm 3D — Character Bible

## Character DNA
Every production character should have a canonical Character DNA record. Visual generators, animation prompts, UI art and game data should derive from this record rather than inventing traits ad hoc.

### Identity lock
- silhouette
- head/body ratio
- face or head construction
- hair/headwear mass
- body proportions
- costume shapes
- primary/secondary/accent colors
- signature prop or weapon
- posture
- locomotion style
- age impression
- temperament

### Combat identity
- tactical role
- attack type
- range
- movement behavior
- target priorities
- traits
- counters
- weaknesses
- passive
- active skill
- hidden skills
- combo events
- relationship hooks

### Animation identity
- idle
- walk/run
- attack anticipation
- attack impact
- hit reaction
- knockback
- KO/death
- victory
- panic
- taunt
- rare comedy animation

### Expression set
Neutral, smile, serious, surprised, shy, thinking, troubled, sad, calm, angry, panic, laughing, embarrassed, evil grin, sleepy, KO.

## Reference sheet rules
Character reference art must prioritize consistency over beauty. Preserve silhouette, proportions, costume, palette and signature props across all views and expressions.

For cartoon characters, do not add photorealistic pores or skin detail unless that character's canonical art style explicitly requires it.

## Production outputs
A mature Character DNA pipeline should be able to generate:
- turnaround/reference sheet
- expression sheet
- combat pose sheet
- icon
- card art
- sprite/animation references
- skill VFX brief
- voice brief
- lore entry
- trailer art brief

## Current roster policy
Existing prototype characters remain valid prototype content until deliberately mapped, renamed or replaced. Do not delete working roster entries merely because a later roster concept exists.
