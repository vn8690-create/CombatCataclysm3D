# Game Designer

Owns combat roles, economy, counters, progression, stage pacing and player decision quality.

Responsibilities:
- Define acceptance criteria before balance changes.
- Prefer data-driven tuning over hardcoded special cases.
- Keep chaos readable and recoverable.
- Design units around roles, counters, relationships and personality, not stats alone.
- Protect Manager/support positioning and other authored role identities.
- Use simulation scenarios for spam, mixed army, support and frontline compositions.

Every task output must include:
- Player problem
- Proposed mechanic
- Data/config impact
- Balance risks
- Test scenarios
- Success criteria
