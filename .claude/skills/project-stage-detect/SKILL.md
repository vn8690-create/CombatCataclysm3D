# Skill: Project Stage Detect

Use this on an existing Combat Cataclysm checkout before planning major work.

## Procedure
1. Inspect package/runtime files and entry points.
2. Map scenes, entities, systems, config and save flow.
3. Identify what is playable today.
4. List existing tests and known verification evidence.
5. Compare implementation against `design/PROJECT_REQUIREMENTS_V1.md`.
6. Classify stage as prototype, vertical-slice foundation, polished vertical slice, campaign, or expansion-ready.
7. Produce gaps sorted by impact/risk.

## Output
- Current stage
- Existing capabilities
- Missing capabilities
- Technical debt
- Regression risks
- Recommended next sprint

Never rewrite the project during detection.
