# Combat Cataclysm 3D

A comedy-first 3D side-view lane-defense game built with Three.js.

## Core philosophy

- Funny > Realistic
- Funny > Balance
- Funny > Logic
- Animation tells the joke. Text delivers the punchline.

This repository is being adopted as the canonical source for the existing local prototype. The current playable prototype includes menu, stage selection, battle flow, win/lose states, upgrades, local save data, units, enemies, bosses, economy, waves, combat, VFX, and smoke tests.

## Safety rule for coding agents

Do not rewrite working systems without first documenting why. Prefer additive, reversible changes with tests and small commits.
